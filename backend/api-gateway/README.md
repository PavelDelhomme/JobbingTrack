# API Gateway

[← Backend](../README.md) | [← README principal](../../README.md) | [📚 Documentation](../../docs/README.md) | [🧭 Navigation](../../docs/navigation.md)

Point d'entrée principal pour toutes les requêtes API du système JobbingTrack. Gère le routage, l'authentification et la documentation OpenAPI.

## 🚀 Démarrage rapide

```bash
# Depuis la racine du projet
make up                # Démarrer tous les services
make logs-gateway      # Voir les logs de l'API Gateway
```

**Port** : 3000  
**URL** : http://localhost:3000

Pour plus d'informations, consultez la [documentation API](../../docs/api/api-reference/README.md).
