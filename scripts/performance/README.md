# Scripts Performance

Scripts de benchmark, comparaison et exécution de tests de performance.

## Entrées

- `performance-benchmark.sh` : benchmark before/after léger.
- `benchmark-all-backoffice.sh` : benchmark complet des pages backoffice.
- `compare-benchmark.sh` : comparaison du benchmark léger.
- `compare-all-backoffice.sh` : comparaison du benchmark backoffice complet.

Ces scripts supposent une exécution depuis la racine du dépôt ou se replacent à la racine au démarrage.
