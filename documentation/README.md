## 🔄 Maintenance

### Ajout de Nouvelle Documentation
1. **Déterminer le type** : guide, API, déploiement, technique
2. **Créer le sous-dossier** approprié si nécessaire
3. **Placer le fichier** dans la catégorie correspondante
4. **Mettre à jour** ce README avec les références

### Mise à Jour du CHANGELOG
- Ajouter les nouvelles entrées en haut du fichier
- Respecter le format standard (date, version, description)
- Inclure les numéros de commit/PR quand applicable

### Génération du PDF
- Utiliser un générateur de PDF à partir des fichiers Markdown
- Mettre à jour régulièrement pour refléter l'état actuel
- Inclure diagrammes et captures d'écran
