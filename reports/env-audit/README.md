# Rapports d’audit environnement / secrets

Placez ici vos inventaires **hors dépôt** (fichiers locaux uniquement), par exemple :

- `inventaire-YYYYMMDD.md` — tableau variables / sensibilité / rotation (valeurs **masquées**).

**Ne committez jamais** de secrets en clair. Procédure : **`docs/operations/PRE_VPS_ENV_AUDIT_AND_UPDATES.md`**.

Les fichiers ajoutés dans ce dossier (sauf ce README) sont **ignorés par Git** (voir **`.gitignore`**).
