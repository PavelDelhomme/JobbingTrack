## 🚀 Commandes Make Importantes

```bash
# Démarrage
make up                  # Services essentiels
make up-full             # Tous les services
make up-with-mobile      # Tout + Mobile (NOUVEAU !)

# Tests
make test                # Tous les tests
make test-e2e            # Tests E2E

# Développement
make help                # Aide complète
make help-services       # Aide services
make help-tests          # Aide tests

# Documentation
make help-documentation  # Génération PDF
```
