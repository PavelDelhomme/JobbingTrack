502 Bad Gateway

Le frontal applicatif ne répond pas

Nginx a reçu la requête mais n’a pas pu joindre le service en amont (souvent le conteneur frontend ou api-gateway est arrêté, en erreur ou encore en démarrage).

  • Vérifiez make status puis les logs du service concerné.
  • Après un changement de code ou d’image, un make recreate ou un redémarrage ciblé peut être nécessaire.
